# 📊 Super Store Sales Dashboard (Power BI)

## 📌 Project Overview
This project presents an interactive **Sales Dashboard** built using Power BI to analyze retail performance across different regions, categories, and time periods. The dashboard provides key insights into sales, profit, and customer behavior to support data-driven decision-making.

## 🚀 Features
- KPI tracking: Total Sales (445K), Profit (59K), Quantity Sold (6402)
- Monthly Sales and Profit analysis (Year-over-Year comparison)
- Regional performance analysis (Central, East, South, West)
- Segment-wise and Category-wise sales distribution
- Shipping mode and payment mode insights
- Interactive filters and slicers for dynamic exploration

## 📊 Dashboard Insights
- Identified sales trends and seasonal patterns using monthly YoY analysis  
- Compared profitability across product categories (Technology, Furniture, Office Supplies)  
- Analyzed customer segments (Consumer, Corporate, Home Office)  
- Evaluated shipping modes impact on sales performance  
- Visualized geographic sales distribution across states  

## 🛠️ Tools & Technologies
- Power BI  
- DAX (Data Analysis Expressions)  
- Power Query (Data Transformation)  
- Data Modeling  
- Data Visualization
